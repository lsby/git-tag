# lsby-git-tag

> 一个基于形式概念分析 (FCA) 的 Git 仓库标签管理工具。

通过引入形式概念分析 (FCA)，将标签系统与层级导航结合，为 Git 仓库自动生成动态分类树，并支持与远端进行双向同步。

---

## 💡 设计动机

在日常开发中管理项目时，常见的两种组织方式各存在明显缺陷：

- **伪层级分类**：通过前缀（如 `前端-框架`）手动模拟层级分类。虽能产生层级外观，但层级关系被硬编码在标签名称中，不仅修改父分类时维护成本高，而一个项目只能存放在一个层级下。例如 `vue-cli` 既属于“前端”又属于“工具”，只能被迫二选一，后续检索时容易混淆。
- **简单标签分类**：虽支持多维度标记（如同时打上“前端”与“工具”标签），但在标签数量较多时，列表会显得臃肿无序，缺乏树状目录层层深入、逐级折叠的直观体验。

**本项目提供的体验**：兼顾“多维度标记”与“树状层级浏览”，让你既能像打标签一样灵活归类项目，又能像浏览文件夹一样逐级展开与检索。

---

## 核心特性

### 🏷️ 标签式管理

摒弃传统单一路线的层级文件夹分类，使用多维度标签管理仓库，一个仓库可同时关联多个维度的标签。（支持中文）

### ☁️ 远端双向同步

标签修改会实时同步至远端的 Topics 字段，本地作为数据缓存。在更换设备或重装系统后，配置 Token 即可自动恢复标签数据。

### ⚡ 批量仓库操作

支持在 UI 界面中对远端仓库进行批量打标签、修改信息等操作，提高日常仓库管理效率。

### 🌳 基于 FCA 的动态导航树

结合 FCA（形式概念分析）格图理论与树状结构的层级体验。导航树根据当前选择的标签动态演算结构，自动生成"动态变化，永远合理"的树结构导航。

### 💻 本地开发联动

支持快速克隆，打开项目等操作。

## 🧠 FCA 机制与动态树说明

以下通过简单示例说明“动态树”背后的 FCA 映射逻辑。

假设存在 3 个仓库及其关联标签：

1. `vue` (标签: **前端**)
2. `webpack` (标签: **工具**)
3. `vue-cli` (标签: **前端**, **工具**)

### 1. FCA 概念格 (Concept Lattice)

在 FCA 理论中，上述数据会形成一个有向无环图（概念格）：

```text
          [所有仓库: vue, webpack, vue-cli]
                /                   \
        [前端] (vue, vue-cli)     [工具] (webpack, vue-cli)
                \                   /
             [前端 + 工具] (仅剩: vue-cli)
```

**格图的特点与限制：**
概念格在数学结构上是完备的（无论先选择“前端”还是“工具”，最终都会精确汇合至 `vue-cli`）。但在图形交互界面中，直接展示交错网状图对日常浏览不够直观，通常需要展开为更易用的树状层级结构。

### 2. FCA 树的展开机制

软件将网状格图按需展开为树状结构，主要包含以下两种处理逻辑：

#### 场景一：包含关系 —— 自动确定父子层级

当标签之间存在严格的包含关系时，系统会自动推理并构建父子层级。

**示例**：

1. `vue` (标签: **前端**)
2. `vue-router` (标签: **前端**, **路由**)

由于包含“路由”标签的仓库均包含“前端”标签，系统自动推导“前端”为父节点，“路由”为子节点：

```text
[根目录]
  └── 📂 [前端]  (包含: vue, vue-router)
       └── 📂 [路由]  (包含: vue-router)
```

**特点**：无需手动建立层级结构，“路由”会自动收纳在“前端”下方。

#### 场景二：交叉关系 —— 拆分挂载与多路导航

当标签之间无严格包含关系但存在交集仓库时，系统会将交集节点挂载至关联的分支下方。

**示例**：

1. `vue` (标签: **前端**)
2. `webpack` (标签: **工具**)
3. `vue-cli` (标签: **前端**, **工具**)

展开后的树状结构如下：

```text
[根目录]
  ├── 📂 [前端]  (包含: vue, vue-cli)
  │    └── 📂 [工具]  (包含: vue-cli)   <-- 路径 A：先找前端，再找工具
  │
  └── 📂 [工具]  (包含: webpack, vue-cli)
       └── 📂 [前端]  (包含: vue-cli)   <-- 路径 B：先找工具，再找前端
```

**特点**：无论从“前端”还是从“工具”视角切入，均能通过对应的路径检索到目标仓库 `vue-cli`。每次选择标签后，系统都会重新计算当前筛选结果的层级关系并更新导航树。
